Automação Recorrente (Monitoramento Diário)

Você pode agendar a coleta automática de 2 jeitos super simples:

Opção 1 — Via Antigravity (/schedule)

No chat do Antigravity com esta pasta aberta como workspace, digite /schedule e peça:

Todos os dias às 08:00, execute `npm run sync` na pasta do projeto e me avise se entraram novos Reels ou Stories relevantes no Swipe File.
Opção 2 — Agendador de Tarefas do Windows (PowerShell)

Roda silenciosamente todo dia às 08:00 mesmo com o Antigravity fechado:

schtasks /Create /SC DAILY /TN "SwipeStudioSync" /TR "cmd /c cd /d C:\Users\victo\.gemini\antigravity\scratch\content-swipe-assistant && npm run sync" /ST 08:00 /F
